## Claude Code 官方文件（2026-11）

- Best practices，https://code.claude.com/docs/en/best-practices.md （必讀，延伸閱讀有摘要）。「Claude stops when the work looks done. Without a check it can run, "looks done" is the only signal available, and you become the verification loop」；四級：one prompt、/goal、Stop hook、verification subagent；「Have Claude show evidence rather than asserting success」；plan mode：Shift+Tab、「If you could describe the diff in one sentence, skip the plan」；「If you've corrected Claude more than twice on the same issue ... Run /clear」；`/compact <instructions>`、CLAUDE.md 寫「When compacting, always preserve ...」；Summarize from here／up to here；「Checkpoints only track changes made through Claude's file editing tools ... This isn't a replacement for git」；CLAUDE.md 可用 @path 匯入；Writer/Reviewer；五種 failure patterns。
- Checkpointing，https://code.claude.com/docs/en/checkpointing.md 。每個開始 turn 的 prompt 建 checkpoint；保留 100 個；`/rewind` 或兩次 Esc；Restore code／conversation／both、Summarize from here／up to here；「Checkpointing does not track files modified by Bash commands」；subagent 的編輯多半不還原；「Not a replacement for version control」。
- Permissions，https://code.claude.com/docs/en/permissions.md 。「Rules are evaluated in order: deny, then ask, then allow」；`*` 的比對規則（`Bash(ls *)` 也比對 `ls`）；compound command 每段分開比；「a deny or ask rule covers the invocation Claude usually produces and isn't a security boundary around the program」（`Bash(rm *)` 擋不到 `/bin/rm -rf build/`、`bash -c 'rm -rf build/'`；`Bash(git push *)` 擋不到 `git -C . push`）；bypassPermissions「Only use this mode in isolated environments like containers or VMs」；`permissions.disableBypassPermissionsMode: "disable"`，「A user can set it in their own settings to lock themselves out of bypass mode」，放 managed settings 時不能覆寫；Read／Edit deny 套用到 cat、head、tail、sed、tee 與重導向，不套用到自己開檔的 Python／Node 腳本，要 OS 層級就開 sandbox；`.claudeignore` 沒有作用。
- Permission modes，https://code.claude.com/docs/en/permission-modes.md （兩段都讀了）。v2.1.283 起互動 session 預設 auto；全文沒有提到 auto mode 會改變偏好的 tool。
- Interactive mode，https://code.claude.com/docs/en/interactive-mode.md 。Esc：「Stop the current response or tool call mid-turn so you can redirect. Claude keeps the work done so far」；排隊的訊息「as soon as those tool calls finish, within the same turn」。
- Worktrees，https://code.claude.com/docs/en/worktrees 。`claude --worktree feature-auth`／`-w`，`.claude/worktrees/<name>/`，branch `worktree-<name>`；建議把 `.claude/worktrees/` 加進 .gitignore；`.worktreeinclude`；`git worktree add ../project-feature-a -b feature-a`；「Worktrees ... isolate file edits」。
- .claude 目錄（繁中版），https://code.claude.com/docs/zh-TW/claude-directory （英文版被權限擋，改讀繁中版）。「這些檔案是純文字。任何通過工具的內容都會在磁碟上的文字記錄中結束：檔案內容、命令輸出、貼上的文字」；`projects/<project>/<session>.jsonl` 預設 30 天後清（`cleanupPeriodDays`）；`history.jsonl`「無限期保留」；「文字記錄和歷史記錄在靜止時未加密」；`CLAUDE_CODE_SKIP_PROMPT_HISTORY`、`--no-session-persistence`；`claude project purge`（v2.1.124 起）；.mcp.json 範例 `"NOTION_TOKEN": "${NOTION_TOKEN}"`，「the token never lands in the file」。
- Advanced setup，https://code.claude.com/docs/en/install 。「Native installations automatically update in the background」，下次啟動生效；`DISABLE_AUTOUPDATER` 放 settings.json 的 env；`autoUpdatesChannel: "stable"`；`claude --version` 印出 `2.1.211 (Claude Code)` 這種格式。本文環境 2026-11-06 實際是 `2.1.318 (Claude Code)`。
