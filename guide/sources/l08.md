## 官方定價與文件

- Claude pricing, https://platform.claude.com/docs/en/about-claude/pricing
  Fable 5.1 $10/$50，5m write $12.50，1h write $20，read $0.25（0.025×）。Opus 5.5 $4/$20，$5，$8，$0.20（0.05×）。Sonnet 5.5 $2/$10，$2.50，$4，$0.10（0.05×）。Haiku 5.5 ≤100K prompts $0.10/$0.50，$0.125，$0.20，$0.01；>100K $0.50/$2.50，$0.625，$1，$0.05。「All other models use the standard 0.1x multiplier」。5m write 1.25×、1h write 2×。Batch 50%。Fast mode Opus 5.5 $8/$40，不能和 batch 併用。Claude 4.6 以後（Haiku 5.5 除外）1M context 同價。
- Claude prompt caching, https://platform.claude.com/docs/en/build-with-claude/prompt-caching
  順序 tools → system → messages；100% identical；最多 4 breakpoints；automatic：top-level `cache_control={"type":"ephemeral"}`；TTL 5m／`"ttl":"1h"`；clock 從 request 開始算；`total_input_tokens = cache_read_input_tokens + cache_creation_input_tokens + input_tokens`；invalidation 表（tool definitions 全失效、`output_config.effort`、`tool_choice` 等）；mid-conversation：加 `{"role":"system"}` message 不動 prefix。
- Cache diagnostics, https://platform.claude.com/docs/en/build-with-claude/cache-diagnostics
  `diagnostics={"previous_message_id": r1.id}`；回傳 `cache_miss_reason.type` = model_changed / system_changed / tools_changed / messages_changed…，範例 `cache_missed_input_tokens: 41850`。
- Batch processing, https://platform.claude.com/docs/en/build-with-claude/batch-processing
  「most batches finishing in less than 1 hour」、50%、24 小時到期；cache 與 batch 可疊；batch 的 cache 命中率「30 percent to 98 percent」，建議 1h TTL。
- Fast mode, https://platform.claude.com/docs/en/build-with-claude/fast-mode
  up to 2.5x OTPS；不改 TTFT；Opus 5.5 $8/$40；不同 speed 不共用 cache；不能用 Batch。
- Claude Code prompt caching, https://code.claude.com/docs/en/prompt-caching.md
  Actions that invalidate：切 model、改 effort（Opus 5.5、Sonnet 5.5、Haiku 5.5、Fable 5.1 用 API key 或訂閱時保留）、開 fast mode、MCP 變動、compaction…。TTL：訂閱 main 1h、API key 5m；subagent 5m；`promptCacheTtl`、`CLAUDE_CODE_PROMPT_CACHE_TTL`；驗證 `claude -p "hello" --output-format json` 看 `usage.cache_creation`。Compaction：warm 時讀 cache，「costs a fraction」；冷的時候「reprocesses the full history as uncached input」。`opusplan` 每次切換都是 model switch。
- Claude Code costs, https://code.claude.com/docs/en/costs
  「around $13 per developer per active day and $150-250 per developer per month ... below $30 per active day for 90% of users」；`/usage` 範例 `claude-sonnet-4-6:  1.2k input, 5.3k output, 940.0k cache read, 50.0k cache write ($0.55)`；`Prompt cache (main):   14 requests · 91% of input tokens from cache · 2 misses (last 6m 10s ago, 310.2k tokens re-cached) · ...`；agent team 約 7 倍 token（plan mode）；`/clear` costs nothing。
- Claude Code monitoring, https://code.claude.com/docs/en/monitoring-usage
  `CLAUDE_CODE_ENABLE_TELEMETRY=1`、`OTEL_LOGS_EXPORTER=console`；event `claude_code.tool_result` 有 `duration_ms`、`tool_name`；`claude_code.api_request` 有 `cost_usd`、`duration_ms`、`cache_read_tokens`、`cache_creation_tokens`。
- GPT-5.6 Sol, https://developers.openai.com/api/docs/models/gpt-5.6-sol
  $4 / cached $0.40 / output $20；cache write 1.25×；prompt 超過 272K：2× input、1.5× output；promotional pricing 至少到 2026-11-21。
- Gemini pricing, https://ai.google.dev/gemini-api/docs/pricing
  Gemini 4 Argon：$2 input、$0.10 caching、$10 output 到 2026-11-30；2026-12-01 起 $4、$0.20、$20。Batch 減半。Gemini 3.8 Flash：$0.75、$0.075、$3.75 到 2026-12-31；storage $0.50/1M/hour。

## 研究與工程文章

- Zhu 等，TraceLab，2026-06-25（arXiv 2606.30560，2026-06-29），https://syfi.cs.washington.edu/blog/2026-06-25-tracelab/ 。作者自己的 Claude Code 與 Codex，約 4,300 session、55B token、433K tool call。Cached 52.56B、new 2.34B、output 186.9M，input:output 294×。命中率 95.7%。「Of the 2.3 B append tokens processed, only 19% represent genuinely new context」「the other 81% is repeated work」「every new token is prefilled roughly 5× on average」，原因是 cache 過期加使用者停頓。Generation ~13 s，tool call ~18 s。「calls under 1 s are ~61% of all calls but only ~1% of total tool time」「the ~4% of calls lasting over a minute consume ~85% of it」。平均停頓 46.7 min、中位數 ~1.4 min。88% 的 LLM round 回應 tool 結果。每個 request 8.8 個 step。作者提醒 trace 偏向自己的習慣。作者沒有算花費。
- Lumer 等，Don't Break the Cache，2026-01-09，arXiv 2601.06007（v2 Table 2）。DeepResearch Bench，每個條件 40 session，10K system prompt。成本降：GPT-5.2 79.3–81.4%，Claude Sonnet 4.5 77.8–78.5%，Gemini 2.5 Pro 27.8–41.4%，GPT-4o 45.9–47.8%。TTFT：−8.8%（GPT-4o full context）到 +30.9%。
- Voss（Arize，與 Fireworks），Cost per Successful Task，2026-07-23，更新 2026-09-29，https://arize.com/blog/cost-per-successful-task-ai-model-benchmark.md 。Terminal-Bench 40 題，10 model，每組 6 次，2,400 run，$626。±6 點。表：gpt-oss-120b 33% $0.018 $0.054；GPT-5 41% $0.317 $0.769；GPT-5.5 67% $0.424 $0.636；gemini-3.5-flash 23% $0.288 $1.233。Coverage（6 次過 4 次）：gpt-oss-120b 8/40、GPT-5.5 25/40。「Results are directional, not a leaderboard score」。文章沒說有沒有用 cache。
- Shihipar，Lessons from building Claude Code: Prompt caching is everything，2026-04-30，https://claude.com/blog/lessons-from-building-claude-code-prompt-caching-is-everything 。「we run alerts on our prompt cache hit rate and declare SEVs if they're too low」「A few percentage points of cache miss rate can dramatically affect cost and latency」。
- Martin，Reducing cost and improving performance with Claude Platform，2026-09-08，https://claude.com/resources/articles/reducing-cost-and-improving-performance-with-claude-platform（必讀，延伸閱讀有摘要）。Fable 5 FrontierCode Diamond low 11.5% $5.35、max 30.9% $19.00；Fable 5.1 HLE low ~53% ~$0.30、max ~61% ~$2.23。分數沒有明說是通過率。Model ID 從 Opus 4.8 換到 Opus 5.5 省約 18%。「Avoid synchronous tool calls and subagents that outlive the cache TTL」。
- Medisetty，Running a Software Factory Efficiently at Uber Scale，2026-08-27，https://www.uber.com/blog/efficient-software-factory/（必讀，延伸閱讀有摘要）。週活躍使用者 7×，週請求 9.4×；每 session 成本從 6 月高峰降 52%；「The subagent default setting has proven to be the most impactful lever」；compaction 400K；互動 session 改 1h TTL，subagent 維持 5m；避開硬上限，statusline 加 50/80/100% Slack 提醒；Managed agent 看 cost per merged PR。
- Martin、Cemaj、Cohen，Scaling Managed Agents: Decoupling the brain from the hands，2026-04-08，https://anthropic.com/engineering/managed-agents 。Session／harness／sandbox。「p50 TTFT dropped roughly 60% and p95 dropped over 90%」（原因：不再每個 session 先配 container）。「the tokens are never reachable from the sandbox」。`wake(sessionId)`、`getSession(id)`、`emitEvent(id, event)`、`getEvents()`、`execute(name, input) → string`、`provision({resources})`。文章沒有談多出來的服務邊界的維運成本。
- aatiya，GPT-5.6 Luna costs ~96% more than GPT-5.4 mini，OpenAI Developer Community，2026-07-11，https://community.openai.com/t/gpt-5-6-luna-costs-96-more-than-gpt-5-4-mini-in-a-controlled-multi-turn-responses-api-test/1386460 。單一使用者自己回報。原因：「invalidating the reusable prefix by putting mutable chat context in top-level instructions」。修好後 Luna 的溢價 96% → 16.7%，GPT-5.4 mini 命中率 50.5% → 75.1%，成本降 37%。
- Ji，Context Engineering for AI Agents: Lessons from Building Manus，2025-07-18，https://manus.im/en/blog/Context-Engineering-for-AI-Agents-Lessons-from-Building-Manus 。「the KV-cache hit rate is the single most important metric」、input:output 約 100:1、JSON key 順序不穩會破 cache。
