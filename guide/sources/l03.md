## 論文、報告
- METR，Becker、Rush 等，2025-07-10，https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/：16 人、246 issue、RCT；慢 19%；事前估快 24%，事後仍以為快 20%。
- METR，Becker、Rush、Cunningham、Rein、Mahamud，2026-02-24，https://metr.org/blog/2026-02-24-uplift-update/：57 人、143 repo、800+ task；舊成員 −18%（CI −38% 到 +9%），新成員 −4%（−15% 到 +9%）；"an unreliable signal"；30–50% 跳過不想手做的任務；同時跑多 agent 時時間量不準。
- Faros AI，2026-04-12，https://faros.ai/blog/ai-acceleration-whiplash-takeaways：22,000 developers、4,000+ teams，兩年 telemetry，比同組織 AI 採用最低與最高的時期。Epics +66%、task +33.7%、PR merge +16.2%；median time in review +441.5%；first review +156.6%；bugs per dev +54%；merged no review +31.3%。廠商報告、相關不是因果。
- Faros AI，2026-09-18，https://www.faros.ai/blog/ai-speed-trap-takeaways：merged without review +76.3%；time in QA +300.6%；monthly incidents +125.4%。
- Anthropic，Shen、Tamkin，2026-01-29，https://www.anthropic.com/research/AI-assistance-coding-skills：52 人 RCT；quiz 約 50% vs 67%；d=0.738，p=0.01；不是 agent 工具，作者說可能更大。
- CooperBench，Khatua 等，arXiv 2601.13295v2，2026-01-26，https://arxiv.org/html/2601.13295：652 task pair；平均低 30%；GPT-5、Claude Sonnet 4.5 兩人只有 25%，約比 Solo 低 50%；2/3/4 agent 68.6/46.5/30.0。
- Carlini，Anthropic，2026-02-05，https://www.anthropic.com/engineering/building-c-compiler：16 agents、約 2,000 sessions、2B input、140M output、略低於 $20,000、約 100,000 行；"Every agent would hit the same bug, fix that bug, and then overwrite each other's changes"；verifier "nearly perfect"；GCC oracle。
- CAVEWOMAN，Adeyemi、Rossi、Dernoncourt，arXiv 2606.24083：8 models、5 datasets；input 壓縮 1.15×（最壞 1.8×，更深約 2.7×），正確率掉；output 壓縮 1.4–2.4× 便宜。
- JetBrains，2026-07，https://blog.jetbrains.com/ai/2026/07/speak-to-ai-agents-like-cavemen-tosave-tokens/：SkillsBench 86/87 task，82 組配對，claude-sonnet-5，p = 0.82，592k → 542k（8.5%）。
