## 第 2 章：harness 的實驗

- Sydney Lewis, Same Model, Different Harness, arXiv 2608.26218v1, 2026-08-26. https://arxiv.org/pdf/2608.26218 [讀原文]
  - Model：Qwen3.6-35B-A3B，llama-server 本地跑，4-bit。
  - Control：完整時間序的 transcript；放不下 window 時 run 直接停（"the run stopped when that conversation no longer fit in the context window"）。
  - Treatment：保留完整紀錄，給 model 較小的 view；prompt 到 window 50% 開始縮短舊輸出；最新 4 筆原文；4,096 字元（第 4–7 筆）、2,048（8–15）、1,024（16–31）、512（32–63）、256（更舊）；保留頭尾；固定規則偵測重複失敗的指令、重複的錯誤、只讀不改；介入提示換做法。
  - Verified，169 題：20,480 token 43→72；43,008 token 76→87（p=0.0614）；262,144 token 102→101（p=1，事後換算的 common-cohort）。
  - Pro，316 題：49,152 token 31→72；262,144 token 101→99。
  - F2PF：Verified 28%→49%，Pro 15%→33%。
  - 用量（control/treatment）：Verified 37.8M/80.7M prompt tokens、3,280/6,517 turns；Pro 210.6M/657.1M、8,357/25,750 turns。
  - 限制：每題一條 greedy trajectory；只測 4 個本地 4-bit 開源 checkpoint；沒有逐項消融；跨 window 的順序不能把 window 大小和 run-era 分開。
  - 結論："the model and harness should be evaluated together as the tested solver"（摘要轉述）。
- John Yang 等，SWE-agent, arXiv 2405.15793 / NeurIPS 2024. https://arxiv.org/pdf/2405.15793.pdf [讀原文]
  - SWE-bench Lite 300 題，GPT-4 Turbo，temperature 0。Shell-only 11.00%。
  - Editor：w/ linting 18.0、無 linting 15.0、no edit 10.3。Search：summarized 18.0、iterative 12.0、no search 15.7。Viewer：30 行 14.3、100 行 18.0、full file 12.7。Context：last 5 obs 18.0、full history 15.0、無 demo 16.3。
  - "agents tend to look through every match exhaustively"；"Either too little content ... or too much ... lowers performance."
  - 全 test set 12.47%（286/2,294）；Lite 18.00%（54/300）。SWE-bench 2,294 題、12 repos。
- Lodha 等（Microsoft），Less Context, Better Agents, arXiv 2606.10209v1, 2026-06-08. https://arxiv.org/html/2606.10209 [讀原文]
  - GPT-5，50 題報帳：C2 全歷史 71.0%、1,481K token；C3 最近 5 組 tool call 79.0%、535.3K；C4 再加摘要（W=3）91.6%、553.4K。作者：一類 enterprise 工作流的強證據，不是普遍證明。
  - Appendix H：N=3 74.0、N=5 79.0、N=10 80.0。Table 5：stale-state 34/73 → 6/53 → 4；premature termination 9 → 18 → 3（https://arxiv.org/pdf/2606.10209）。
- Xia 等，Diagnosing and Mitigating Context Rot in Long-horizon Search, arXiv 2606.29718. https://arxiv.org/pdf/2606.29718 [讀原文]
  - 四個開源 model；"context window size is not the main bottleneck"；只測開源 model，軟體開發是否適用不明。
- OpenAI，Why we no longer evaluate SWE-bench Verified, 2026-02-23. https://openai.com/index/why-we-no-longer-evaluate-swe-bench-verified/ [讀原文]（主場 L7，只放給主線）
