  靠：這個單位加前文，但「cache miss」要自己選一種意思
  R1 「全班的 log 沒有把 cache miss 分出來」有兩種讀法。照修改後的定義，cache miss 是「讀不到 cache 的部分」（#tldr ¶4），而且「cache miss 的部分記成 cache write」（#i2 ¶4、#i2 圖2 內容），新內容讀不到 cache，也算 cache miss。這樣讀，全班的 log 有 cache write 這一欄（圖 2），cache miss 已經分出來了，這句說不通。這句要讀成「只有過期造成的 cache miss」才通。緊接著的 #i2 圖3 說明（「cache miss 和新內容都照 cache write 收錢」）、#i2 圖3 內容（「cache miss 26%，新內容 6%」）和 #i2 ¶9 也都用這個窄的意思，把新內容排在 cache miss 外面。同一個 cache miss，在 #i2 ¶4 和圖 2 包含新內容，在這裡和圖 3 不包含，沒有一句話說換了範圍（#i2 ¶10 寫了「過期造成的 cache miss」，但那是在這幾處之後）。
