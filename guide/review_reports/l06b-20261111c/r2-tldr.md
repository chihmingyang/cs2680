BLOCK [#tldr ¶2]
  我讀到的：agent 跨對話留下的筆記叫 memory；agent 是 model 加一層外面的程式，model 自己不記事，它「記得」的都是那層程式從筆記讀出來放進對話的字，所以筆記壞了它不會發現，每次新對話都再照做；這堂課要回答在哪三個地方把壞筆記擋下來。
  靠：我自己的知識
  R2 「Agent 是 model 加上包在它外面的一層程式」的 model 指哪一個，指不出來。¶1 唯一出現的 model 是「我們用 vLLM 跑 model」，那是專案要部署的 model。這裡的 model 是 agent 裡面的那一個。文章沒有說這是兩個不同的 model。我得自己判斷「agent 裡的 model 應該不是團隊用 vLLM 跑的那一個吧」。照字面也可以讀成同一個，那樣 6 月換掉 vLLM 就變成在換 agent 自己，例子的意思就變了。

BLOCK [#tldr ¶5]
  我讀到的：agent 找筆記是挑和問題意思最像的幾條；7 月它找「現在用哪一套程式」，「用 vLLM」和「用 SGLang」兩條一樣像，分不出新舊，所以要先把標了「到 6 月為止」的篩掉再比；別的專案、別的使用者的筆記也要先篩掉。
  靠：我自己的知識（最後一句）
  R9 「別的專案、別的使用者的筆記也要先篩掉」後面給的理由只有「一份筆記常常是好幾個專案共用的」。這句只撐得住「別的專案」。「別的使用者」的筆記為什麼會在我的 agent 的筆記裡，文章沒說；¶1 寫的是「自己的筆記」，我原本讀成一個 agent 一份。
  R9 前半句的篩法有寫（看「到 6 月為止」的標記）。這一句的篩法沒有寫：靠什麼認出一條筆記是別的專案或別的使用者的？¶4 要求寫的只有「從什麼時候開始」和「是誰說的」，沒有「屬於哪個專案」。
  R16 ¶2 說「下面每一條都回到上面的例子」。這一句在例子裡對不到任何東西：例子只有一個專案、一個使用者，也沒有因為拿到別人的筆記而出錯。「裡面的內容看起來也很像」是和什麼像，也要自己補。

NIT [#tldr ¶1]
  我讀到的：4 月你告訴 agent 專案用 vLLM 跑 model，它記進筆記；6 月換成 SGLang，它多記一條，舊的沒動；7 月再寫部署 script 時兩條相反的紀錄並存、沒有標記，它照舊的 vLLM 寫完並回報完成，部署失敗你才發現。

NIT [#tldr ¶4]
  我讀到的：每條筆記要寫上從何時成立、誰說的；兩條寫成「4 月起用 vLLM」「6 月起用 SGLang」就看得出新舊，記新的時候再替舊的補「到 6 月為止」而不刪，只剩一條算數、也答得出 5 月用什麼；「誰說的」用在衝突時，你親口說的不該被網頁上的一句話蓋過；這兩件事要當下寫，事後得翻對話，對話沒留就補不回來。
  靠：這個單位加前文
  R7 「agent 在某個網頁上讀到的一句話」突然出現。前面的 agent 只會讀檔、跑指令、改 code，筆記裡的兩條都是你親口說的；文章沒說 agent 也會把網頁上讀到的東西記進筆記。「是誰說的」這一半因此沒有回到例子（例子裡兩條的來源相同），和 ¶2 的「每一條都回到上面的例子」接不上。
