BLOCK [#i4 註 n-harness 表1 列4 ‹獨特的設計›]（列名：Pi）
  我讀到的：Pi 有三個設計。一，核心很小：預設只有四個 tool，沒有內建 subagent 和核准，其他功能靠 extension 加，MCP 到 2026-10 的 1.0 才有。二，keep-alive 是在 prompt cache 過期前送一個 request 續命；每送一次要付錢，所以 Pi 先估省得夠不夠多才送。三，它有一個函式庫 pi-ai 給別的專案用，支援 42 家 model 供應商、10 種 wire API。
  靠：我自己的知識（「續命會省錢」是我補的）
  R9 「所以只在預期省得夠多時才送 keep-alive」：省的是什麼，沒寫。這一句只寫了成本（每送一次要付錢），沒寫收益：cache 不過期為什麼會省錢、過期了要多付什麼。文章沒說為什麼續命會省。prompt cache 在 [#i4 ¶2] 只說是 L8 的詞，審查包裡沒有解釋。
