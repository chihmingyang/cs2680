NIT [#tldr ¶1]
  我讀到的：團隊的 agent 帳單太高，把 model 換成單價較低的一級，結果下個月帳單沒降、做成的任務更少，因為便宜的 model 常失敗，失敗要重跑，重跑也要付錢。
  靠：這個單位加前文
  R1 「失敗的任務要重跑」和「做成的任務還變少了」放在一起，我停了一下：既然重跑了，為什麼做成的還是變少？文章沒說重跑之後仍然有做不成的。意思猜得到，不會讀錯方向。

NIT [#tldr ¶4]
  我讀到的：agent 每一步都把到目前為止的全部內容再送給 model 一次，這是最大的花費；廠商會把上次送過的開頭存成 cache，下一步的開頭和上次完全相同就算命中、照折扣價收，沒命中的 token 單價是命中的 12 到 50 倍；保住命中只要開頭不變、不用丟內容，所以先做。
  靠：這個單位加前文
  R2 「開頭」指到哪裡為止，這一句沒說：是上一次送出的全部，還是其中前面一小段？我讀成「和上一次相同的那一整段」，但要自己判斷。
  R12 「12 到 50 倍」有標籤（沒命中對命中的單價），但沒說這個範圍是隨什麼變動的；導讀層級可接受。
