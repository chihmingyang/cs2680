BLOCK [#tldr ¶2]
  我讀到的：課程收了 58 位學生三份作業的 Claude Code 紀錄；用量漲了 4.5 到 7.2 倍，學生自己抓到的 agent 錯誤比例從六成掉到三成；這堂要回答人該守住哪幾件事，下面三條「依代價由大到小排」。
  靠：這個單位加前文；最後一句靠我自己猜
  R1 「依代價由大到小排」有兩種讀法：照做這一條要花的工夫，或是沒守住時的損失。兩種讀法排出來的順序意思相反。
  R2 「代價」是誰的、什麼的代價沒有寫。照「損失」讀，第三條（¶5）是「拿不回來的事」，看起來損失最大，卻排最後；照「工夫」讀，也看不出第一條為什麼最費工。讀者對不回任何一種讀法。

BLOCK [#tldr ¶4]
  我讀到的：比較兩種做法時一次只改一件事、每種跑多次；例子是我改了程式一個地方，同一份程式碼重跑評分會在 16 到 18 題之間跳，所以多過一題不算變好；Claude Code 自己會變，所以新舊做法要同一段時間交錯跑。
  靠：只靠主張、例子對不上
  R16 主張講「兩種做法」，例子講「你改了程式的一個地方」。我指不出例子裡的「做法」是哪一樣：是我的程式碼的新舊兩版，還是兩種使用 Claude Code 的方式。後半句「舊做法和新做法」也對不回例子裡的「程式」。
  R2 「同一份程式碼重跑一次評分」和「今天跑和明天跑」是誰在跑、跑什麼沒有寫。讀成「重跑我的程式的測試」，那 Claude Code 改變行為就和這件事無關，題數也不該跳；讀成「讓 Claude Code 重做一次作業再評分」，那「同一份程式碼」就說不通。兩種讀法都卡住。
  R15 「分數」「評分」「通過的題數」在這一段交替出現；¶1 只有「通過的題數」。「分數有沒有變好」是不是就是通過的題數，要自己判斷。

NIT [#tldr ¶5]

  靠：這個單位加前文
