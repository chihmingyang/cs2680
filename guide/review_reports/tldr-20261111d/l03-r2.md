BLOCK [#tldr ¶3]
  我讀到的：例子裡切任務、合併、review 佔兩成，只能照順序做；其餘八成分給 16 個 agent，時間縮成「原來的二十分之一」；兩者相加是四分之一，所以只快 4 倍。
  靠：這個單位加前文，但「二十分之一」要靠下一句的加法倒推才知道分母是什麼
  R2 「花的時間是原來的二十分之一」沒說「原來」是誰。照句子的主詞（剩下的八成）讀，是「那八成的時間縮成自己的二十分之一」；可是 16 個 agent 對應的應該是十六分之一，讀者會卡在「16 個為什麼是二十」。要讀到「兩成加二十分之一是四分之一」，才倒推出分母是整件工作原本的時間（八成除以 16）。
  R12 「二十分之一」沒有標籤說它是佔什麼的比例；「兩成」和「二十分之一」相加，讀者要自己確認兩個是同一個分母。

BLOCK [#tldr ¶5]
  我讀到的：只要結果，就派一個 agent 做完交回摘要（subagent）；要互相討論才組隊；「多到一段對話管不過來」時把分派流程寫成 script；必然發生的步驟寫進程式，要判斷的留給 model。
  靠：這個單位加前文；「一段對話」是猜的
  R2 「多到一段對話管不過來」沒有主詞：什麼多？agent、任務，還是討論？「一段對話」是誰和誰的對話也沒寫。前一句剛講「幾個 agent 得互相討論」，所以最順的讀法是「agent 之間的討論太多」；但後半句接「分派的流程」，看起來指的是你用來指揮 agent 的那段對話。讀者沒用過 agent 工具，不知道分派是在一段對話裡做的，兩種讀法分不出來。
