BLOCK [#tldr ¶4]
  我讀到的：能讓 agent 自己跑多久，看成果能不能被檢查：做完的條件要能用測試或指令查，判定做完的要是另一個 model，越難回退的工作越不能放手。
  靠：這個單位加前文；「另一個 model」有兩種讀法
  R1 「另一個 model」：¶1 把 model 定義成 agent 裡面做決定的語言模型。這裡可以讀成「換一家、換一款語言模型」，也可以讀成「另外開一個 agent 來判」，我分不出來。
  R9 前半句說做完的條件用測試或指令檢查，後半句說判斷做完的要是另一個 model。測試已經能查了，為什麼還要一個 model 來判，中間少一步。「打高分」也突然出現：前面沒說過 model 會替成果打分數。
  R15 「放手」「自己跑久一點」「自主」三個詞在同一段。「給越少自主」是指跑的時間短一點，還是每一步都要我同意，讀不出來。
  R7 ¶1 說每一份我都要 review，¶3 說上限由我 review 的速度決定，這裡說「16 份成果你不可能逐行看」，沒有一句話交代 review 和逐行看的差別。
