# 整站刪除測試（2026-11-25）

起因：James 問導讀的「先看一個例子。」為什麼過得了精簡，接著說「整站掃一次」。規則在 STYLE_ARTICLE 第 0 節〈精簡〉第 9 類。

做法：13 堂各一個全新的審查者，只拿整頁的審查包和 `PROMPT.md`，列出刪掉後讀者沒有少知道一件事的句子（A 只安排閱讀、B 重複、C 空話），一堂最多 20 句。主線逐句判斷，`apply.py` 的 `ACC` 是決定刪的。

結果：224 句候選，刪 101 句（A 81、B 9、C 11；`apply.py` 沒對到的 9 句裡，紅字的 5 句和 L11 一句不刪，L4 的兩句「下面有例子。」和 L8 的兩處「看下圖：」手動刪）。各堂的候選在 `lXX.json`。

沒刪的 123 句，理由分五種：

- **章首的路線句**（「這一章先講 X，再講 Y」）：R14 要章首說這一章回答什麼，留。
- **帶出處或範圍的引句**（「課程的修法有三條：」「官方文件的 CI 寫法是：」「下面是文章的原圖。」）：冒號前面說了是誰的、哪裡來的。
- **圖說和內文重複**（L4、L8、L9、L10 最多，約 35 句）：要決定留圖說還是留內文，是改稿，不是刪句；留給那一堂下次審查。
- **收合註裡重複主線的句子**：註是單獨查閱的，要能自己站得住。
- **紅字的句子**（5 句，和小標同義）：紅字是讀者的掃讀路徑，要動得連紅字一起重排，留給 mark-red。

審查者標錯一處：L9 `#i8-5` 的「這改變三件事。」是小標，不是句子，沒刪。小標本身只有數量、沒有內容，`outline.py lint` 該抓，留給 L9 改標題時處理。

導讀的「下面三條是這堂的判斷。」10 堂一起拿掉，STYLE_ARTICLE 導讀那一條跟著改；L6 那一句後面接了三條各是什麼，留著。
