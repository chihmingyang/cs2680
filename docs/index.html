怎麼讀

一堂講一組互相依賴的觀念，不一定對到一份 slides：9/28 那份 slides 講了兩件互不依賴的事，拆成 L6〈Agent Reliability〉和 L6b〈Agent Memory〉兩堂，可以各自讀。Part I 的建議順序是 L2 → L4 → L3 → L5，不照編號。L2 和 L3 先用到 context 的代價、subagent 這些詞，L4 才解釋它們；先讀 L4，讀 L3 就不用往後翻。L5 要在 L3 之後讀。Part II 照編號讀：L9 從 model 的形狀算出三本帳（weights、每個 token 的運算、每個 token 的 KV cache），L10 再用 GPU 的規格判斷這些帳卡在哪裡。L11 是作業回饋與用 agent 的十個陷阱，內容接 Part I 的 L2、L3、L6、L7，建議讀完 Part I 再讀。

  1. 讀文章。「先看這裡」是整堂的結論；核心觀念依重要性排，標「一定要會」的章先讀，「需要時查」的章可以跳過。名詞在第一次出現的地方就有解釋，查閱用的細節收合著，想看再展開。標「本文補的」「本文的判斷」的地方不是 slides 的內容。想對照原始材料，再打開 slides。
  2. 讀完一節，就做那一節最後的「小測」，馬上知道自己懂了沒有。目前 L5、L6、L6b、L7 有，其他講次陸續補上。
  3. 想動手時，照「動手試試」做。裡面有可以照打的設定檔、指令或小練習。
  4. 想對照原文時，看每一堂最後的「原文出處」。那裡只列教授指定的 readings 的標題與連結，是查閱用的，不必讀。

這份筆記的寫法

文字約 75% 遵守 ASD-STE100（Simplified Technical English）的原則。比喻和因果說明保留彈性。

一句一件事

每句只講一個概念。描述句控制在 40 字以內。

主動語態

✓ harness 執行 tool call。

✗ tool call 被 harness 執行。

術語保留英文

context window、harness、prefix cache 等標準術語不硬翻。

  • 文章不逐頁重講 slides，也不寫頁碼。它依想法的重要性重組，補背景與課程沒講到的主題。
  • 標「本文補的」「本文的判斷」的地方不是 slides 的內容。外部事實在句子裡附原始來源；只有一家公司的經驗會寫明不是對照實驗。
  • Claude Code 的設定檔與指令已對照 2026 年 10–11 月的官方文件。
  • 「原文出處」列的是課程網站的官方 readings 清單（cs2680.com/readings）。L11 那堂課程沒有列 readings，取自其他講次的官方清單。
  • 「閱讀」時間只算不展開時看得到的文字；講次頁另列「全部展開」的時間，包含深入區塊。
  • 本站不轉載 slides 的圖片。頁碼一律是 PDF 檢視器的頁數，不是 slide 右下角的編號；頁碼連結會開到官方 PDF 的那一頁。
  • 「已讀」標記和小測的作答只存在你自己的瀏覽器。
