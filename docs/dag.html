節點是什麼

  • 一個節點是一個觀念：能用一句話寫成主張、有自己的前置、刪掉它後面某個觀念就讀不懂。
  • 起點是各堂核心觀念的章（v7 版面已經一章一個想法）。一章講兩個前置不同的觀念就拆成兩個節點（例如 L1 第 9 章拆成機率性輸出、測試分兩層、故障是常態）；兩堂講同一個觀念就併成一個節點（例如 Agent loop 來自 L1 與 L2）。

邊是什麼

  • A → B 表示「讀 B 之前要先懂 A」。B 的「為什麼從這裡延伸」那一句要能說出少了 A 哪裡讀不懂。
  • 只畫直接的前置。A → C 能從 A → B → C 推出來就不畫。
  • 邊只看觀念，不看講次。所以會出現前置在後面講次的邊，那正是要找的落差。

難度怎麼分

  • 基礎一句話能說清楚；靠日常經驗或一個前置觀念就能懂；不懂它，後面多數觀念讀不下去。全站 19 個。
  • 進階要同時拿著兩個以上的前置觀念才能懂；通常是在做一個設計決定，或算一次帳。全站 69 個。
  • 專家要進到機制內部（算式、硬體單元、演算法），或要能判斷研究結論的效度；不自己做 serving、harness、評估的人可以跳過，不影響上游的判斷。全站 12 個。

一條規則：前置的難度不能比這個觀念高。基礎觀念不能依賴進階觀念，否則不是邊畫錯就是難度標錯。tools/dag.py --check 會擋。
