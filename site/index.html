怎麼讀

  1. 先讀第 5 段「問題討論」的基礎題，每堂最多 5 題。它們依 slide 順序排列，答案都在 slides 裡。
  2. 帶著問題，自己一頁一頁看完 slides。看到對應的頁，把答案記下來；看完展開「參考答案與重點複習」對照。它先直接回答，再把這一題的觀念整理成一份複習筆記，有些附圖；讀書會後也可以只看這裡複習。卡住的地方、跟參考答案不同的點，直接寫在那一題下面的留言串。一題可以留很多則，大家的留言預設展開。
  3. 再讀文章。「先看這裡」和架構圖給你整堂的全貌，核心觀念把主線串起來，「觀念補充」解釋 slides 預設你懂的名詞。部分講次的核心觀念下面有「深入」區塊，預設收合，看 slides 卡住時再展開。
  4. 讀書會前：切到進階題。每一題下面有一格討論區，寫下你的想法，按「儲存」就留下來了。想答幾題就答幾題。每個回答要點下面有一行提示；不知道怎麼開頭，就按「用範本開始寫」，照著填空。主持人可以按「複製進階題」把題目貼到群組提醒大家。
  5. 讀書會上：打開討論總覽，選這一堂。先掃基礎題留言，把共同卡住的地方挑出來；再一題一題看進階題的想法；最後回到講次頁展開「參考觀點與追問」。
  6. 想動手時，照「動手試試」做。裡面有可以照打的設定檔、指令或小練習。
  7. 要分工導讀時，用每一堂最後的「延伸閱讀」。教授指定的 readings 都整理在那裡：每篇有建議等級、一句定位和「導讀」切入點，一人認領一篇就能開場。

留下你的想法

這不是作業，也不打分數。它是把大家的思考留下來的方法。兩種形式：基礎題下面是留言串，一題可以留很多則，照時間排、預設展開，收看 slides 時卡住的地方和想再問的問題。進階題下面是討論區，一人一則：寫下你對那一題的想法，按儲存，其他成員就看得到。其他人的想法預設收合，你寫完後才展開，所以先想自己的，再比較。跨題的補充和附件放在每一堂第 7 段。討論總覽可以選一堂，把每一題和所有人的想法一次攤開，主持人也能在那裡把全部討論下載成一份 Markdown。

這份筆記的寫法

文字約 75% 遵守 ASD-STE100（Simplified Technical English）的原則。比喻和因果說明保留彈性。

一句一件事

每句只講一個概念。描述句控制在 40 字以內。

主動語態

✓ harness 執行 tool call。

✗ tool call 被 harness 執行。

術語保留英文

context window、harness、prefix cache 等標準術語不硬翻。

  • 文章不逐頁重講 slides。它整理架構、補背景、做延伸，並附討論題。
  • 「延伸思考」是本文的推論，不是 slides 的內容。每篇都有標示。
  • 基礎題只問 slides 講了什麼；進階題問你會怎麼做。兩者都維持通用，不綁定特定公司或專案。估算題的參考答案附完整算式。
  • 基礎題的參考答案寫成重點複習：答案、重點拆解、背景補充、常見誤解，最後是帶得走的幾點。「答案」與「重點拆解」以 slides 為準並標頁碼；超出 slides 的內容放在「背景補充」。
  • Claude Code 的設定檔與指令已對照 2026 年 10 月的官方文件。
  • 「延伸閱讀」整理自課程網站的官方 readings 清單（cs2680.com/readings）。必讀等級、時間估計與導讀切入點是本站的編輯建議，不是課程要求。
  • 「閱讀」時間只算不展開時看得到的文字；講次頁另列「全部展開」的時間，包含參考答案、重點複習與深入區塊。
  • 本站不轉載 slides 的圖片。頁碼一律是 PDF 檢視器的頁數，不是 slide 右下角的編號；頁碼連結會開到官方 PDF 的那一頁。
  • 「已讀」標記只存在你自己的瀏覽器。留言和討論區的內容存在這個站台的共用資料庫，登入 claude.ai 的成員都看得到。
