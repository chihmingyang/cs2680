怎麼讀

  1. 先讀第 5 段「問題討論」的基礎題。它們依 slide 順序排列，答案都在 slides 裡。
  2. 帶著問題，自己一頁一頁看完 slides。看到對應的頁，把答案記下來；看完展開「參考答案」對照。
  3. 再讀文章。「先看這裡」和架構圖給你整堂的全貌，核心觀念把主線串起來，「觀念補充」解釋 slides 預設你懂的名詞。
  4. 讀書會前：主持人切到進階題，按「複製進階題」貼到群組。成員寫下自己的答案，貼到那一堂最後的「交作業」。
  5. 讀書會上：一起展開「參考觀點與追問」，比較彼此的答案。
  6. 想動手時，照「動手試試」做。裡面有可以照打的設定檔、指令或小練習。

交作業

每一堂的第 7 段「交作業」收大家對進階題的討論，可以附檔。送出後所有成員都看得到。收作業總表列出誰交了哪幾堂，主持人也能在那裡把全部討論下載成一份 Markdown。

這份筆記的寫法

文字約 75% 遵守 ASD-STE100（Simplified Technical English）的原則。比喻和因果說明保留彈性。

一句一件事

每句只講一個概念。描述句控制在 40 字以內。

主動語態

✓ harness 執行 tool call。

✗ tool call 被 harness 執行。

術語保留英文

context window、harness、prefix cache 等標準術語不硬翻。

  • 文章不逐頁重講 slides。它整理架構、補背景、做延伸，並附討論題。
  • 「延伸思考」是本文的推論，不是 slides 的內容。每篇都有標示。
  • 基礎題只問 slides 講了什麼；進階題問你會怎麼做。兩者都維持通用，不綁定特定公司或專案。估算題的參考答案附完整算式。
  • Claude Code 的設定檔與指令已對照 2026 年 10 月的官方文件。
  • 本站不轉載 slides 的圖片。頁碼連結會開到官方 PDF 的那一頁。
  • 「已讀」標記只存在你自己的瀏覽器。「交作業」的內容存在這個站台的共用資料庫，登入 claude.ai 的成員都看得到。
